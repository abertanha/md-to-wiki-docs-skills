## Artefatos que este plano produz

**Arquivo novo — `templates/lang/en.lang`**

- Formato: uma chave por linha, `chave='valor'` (aspas simples sempre; aspas simples literais no valor usam a sequência de fechar-inserir-reabrir). Sem espaços ao redor do `=`. Sem expansão de shell. UTF-8 sem BOM. Comentários com `#`, prosa em PT-BR, valores em inglês.
- Namespace por prefixo (é assim que as chaves ficam agrupadas por superfície): `site_*` e `nav_*` = superfície MkDocs; `index_*`, `section_*`, `label_*`, `table_*`, `desc_*`, `cell_*`, `generated_by` = superfície index; `pdf_*` = superfície PDF; `swagger_*` = superfície Swagger.
- 33 chaves. 29 são consumidas por `generate-index.sh` neste plano, 3 por `generate-mkdocs.sh` no plano 02-02 (`site_name_suffix` é compartilhada), 2 ficam prontas para a Phase 3 (`pdf_title`, `swagger_title_suffix`).

**Assinatura nova de `scripts/generate-index.sh`**

- `generate-index.sh <project_name> <audience> <output_lang> [feature_base_dirs...]`
- `<output_lang>` é OBRIGATÓRIO (sem default no script). Valores aceitos: `en`, `pt-br`. Normalizado para minúsculo na entrada (`pt-BR` equivale a `pt-br`, PARAM-02).
- Divergência temporária conhecida e aceita: os gêmeos `.ps1` mantêm a assinatura antiga até a Phase 4 (ROADMAP Phase 4, critério 1). O plano 02-02 corrige a afirmação dos READMEs sobre paridade de argumentos.

**Variáveis novas dentro dos scripts** (mesmo nome nos dois scripts, bootstrap replicado deliberadamente — todo script de `scripts/` é autocontido neste projeto, nenhum faz source de outro)

- `OUTPUT_LANG` — o valor normalizado e validado
- `SCRIPT_DIR` — `cd "$(dirname "${BASH_SOURCE[0]}")" && pwd`
- `CATALOG` — `${SCRIPT_DIR}/../templates/lang/${OUTPUT_LANG}.lang`
