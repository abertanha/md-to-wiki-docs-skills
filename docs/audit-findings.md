### 2.2 Structural (❌ verdicts on structure, not runtime)

- **S1** No step anywhere ends on a checkable completion criterion (STE-1/HIE-1 ❌ in 7 files); only mkdocs step-4 (`--strict`) and the pdf Output contract approximate bounds.
- **S2** No external reference home (HIE-5 ❌/⚠️ in every file): 12 shared meanings duplicated per-file — variable vocabulary (2 definition sites + 1 re-derivation), script-call convention (pdf is the outlier), source taxonomy (**4 variants**: by-dir in script, by-filename in pdf, wiki-pages in github-wiki, prose in SKILL.md), dependency map ×5 (Swagger's deps exist *only* in deploy.md), persona line ×8, orchestrator-return contract ×8, discover-sources block ×3, `merged-specs/` ×2, install paths ×3 (divergent: symlink vs copy; `.cursor` scope unresolvable), ask-before-delete ×2 (contradicted by script), format naming ("Pure HTML" vs "MkDocs").
- **S3** deploy.md carries off-phase content: Multi-Directory merge (pre-generation) + Sharing (install guidance) in the post-generation agent.
- **S4** `sources.json` is written by 3 agents and read by nothing repo-wide.
- **S5** SKILL.md has no frontmatter — no description, no `allowed-tools`; invocation mode undeterminable from the file (may be supplied at install time — SR-2 settles it).
